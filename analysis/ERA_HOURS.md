**Generated:** 2026-09-24

Two lenses:

1. **School-path hours** — how long students usually spend in that curriculum band (contact / guided learning).
2. **Quintile study hours** — estimated time to work the map’s primary courses (worked example + practice per topic).

### Assumptions (Quintile study)

- Track topic leaf: **1.25 h** median.
- Higher certificate leaf: **1.0 h**.
- IB AA syllabus leaf: **2.5 h**.
- Skills fluency item: **0.25 h**; paper drill: **0.5 h** (optional).
- **Primary path:** Counting = Measures + First numbers; Workshop = Pre-algebra + Geometry; Secondary = Higher certificate; Bridge = Functions + Precalculus + skills; Diploma = Analysis HL; University = all four footholds; Beyond = both enrichment tracks.
- Pace column uses **5 focused hours/week** of Quintile practice.

Sources for school hours: Ofqual GCSE ~120–140 GLH / A-level ~360 GLH; IB DP SL **150** / HL **240** teaching hours; typical primary/secondary ~3.5–5 h/week math × ~36 weeks.
